iAbout this annotation+

Global alignment uses vamos 3.1.1 scoring. Matches score +20. Mismatches and indels each score −5, including each skipped motif base in a leading gap. Continuing into another copy costs 20 points, even for the same motif. This penalty is disabled if any motif is one base long. Motif IDs (M1, M2, …) follow your input order, and earlier motifs win ties. “Variant” means the observed chunk differs from its assigned reference motif.
