iAbout this annotation+

Annotation uses the string decomposition algorithm. Matches score 0; mismatches and indels each score −1. Motif IDs (M1, M2, …) follow your input order, and earlier motifs win ties. “Variant” means the observed chunk differs from its assigned reference motif; it is not a confidence estimate.
