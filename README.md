# Tandem repeats annotation

sdAnnotation annotates tandem repeat DNA sequences in your browser using the string decomposition algorithm from vamos 3.1.1. [Open the web tool](https://bidagu.github.io/sdAnnotation/) · [vamos](https://github.com/ChaissonLab/vamos)

1. Paste FASTA records or one DNA sequence per line.
2. Enter a shared motif list or select one of 78 predefined loci.
3. Click **Annotate sequences**. Explore the motif and waterfall plots, then download the annotation table (TSV), motif plot (SVG), or waterfall overview (PNG).

Sequences stay in your browser. For offline use, open the standalone `index.html`.

The annotation engine matched the full motif order for all 62,789 available haplotypes across the 78 bioTR loci. [TRCompDB benchmark dataset](https://zenodo.org/records/21961073)
